# Atharva's Analyst Hub

Build a modern, clean, professional personal portfolio website for me.

I am Atharva Thakare, a final-year Bachelor of Engineering student in Artificial Intelligence with experience as a Data Analyst at The Sleep Company from March 2026 to August 2026.

My professional focus is:

- Product Analytics

- Data Analytics

- Web Analytics

- A/B Testing

- SQL

- Python

- Power BI

- Excel

- GA4

- Google Tag Manager

IMPORTANT ARCHITECTURE REQUIREMENTS:

1. Make the main portfolio a single-page website with sections rather than separate pages.

2. The sections should be:

- Home / Hero

- About

- Experience

- Projects

- Skills

- Education

- Resume

- Contact

3. The Projects section MUST be data-driven and reusable.

Do NOT hard-code individual project cards directly into the page layout.

Create a reusable project data structure/component so that I can add new projects in the future by adding project information without redesigning the website.

Each project should support:

- title

- short description

- detailed description

- technologies

- category

- GitHub URL

- live demo URL

- project image/screenshot

- key results

- case study URL/page

4. Design the project cards so that they can automatically display any number of projects.

5. The architecture should allow individual project case-study pages to be added later without redesigning the main portfolio.

6. Make the website responsive for desktop, tablet and mobile.

7. Keep the design professional, minimal and recruiter-friendly. Avoid excessive animations, gradients, glowing effects, or overly flashy designs.

8. The website should feel like a portfolio for a Product/Data Analyst rather than a generic developer portfolio.

9. Keep the code clean and component-based so I can maintain and extend it later.

10. Do NOT implement Google Analytics or Google Tag Manager yet. I will add analytics tracking after the initial website is complete.

For now, focus on creating the website structure, reusable components and visual design.
